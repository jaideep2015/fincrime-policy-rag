# Extraction QA report

Generated by `python -m fincrime_rag.qa`. A flag is a prompt for a human look, not a verdict; thresholds live in `config.yaml` (`qa:`, `ocr:`).

- **Merged pages**: the text layer covered less than the threshold of the OCR word count but is usable, so it is kept as the base and OCR-only lines are added. **OCR-only pages**: no usable text layer (image-only covers, scanned forms); OCR text alone. **Min coverage**: lowest text-layer/OCR word ratio on a judged page.
- **Lines lost**: text-layer lines of 5+ words absent from the final page text (running heads and page numbers that cleaning removed on purpose do not count), as total / on merged pages. It must be 0 on merged pages.
- **Bad-char %** is computed on the raw extracted text (before cleaning, so it still counts Symbol-font private-use bullets such as U+F0B7) and on the cleaned text, shown as raw / cleaned.
- **Residual edge lines**: running-head/page-number lines still present after cleaning (total, split page numbers / head patterns / repeated lines).
- **Printed guess**: pages with a `printed_page_guess`; the number in parentheses is how many guesses were nulled because they broke the document's modal printed-minus-PDF page offset.
